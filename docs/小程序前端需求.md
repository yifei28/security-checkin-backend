# 前端登录逻辑集成指南
*Frontend Login Logic Integration Guide*

## 📋 **文档目的**
本文档为后端开发者（包括 Claude Code）提供详细的前端登录逻辑说明，确保后端API能够正确响应前端的认证请求，实现完整的登录流程。

---

## 🎯 **前端登录流程概述**

### **核心认证模式**
- **主要登录方式**: 微信小程序 `wx.login()` 获取临时凭证
- **补充授权**: 用户手机号获取（可选）
- **存储方式**: AES-256-CBC 加密本地存储
- **Token管理**: JWT格式，支持自动刷新

## 🛠 **前端逻辑关键点**

### **1. 前端自动适配逻辑**
```typescript
// 前端会检测后端响应格式并自动转换
if (response.data && 'success' in response.data) {
    // 处理格式A（自定义格式）
    authResult = response.data;
} 
else if (response.data && response.data.openid) {
    // 处理格式B（微信标准格式）
    authResult = {
        success: true,
        token: response.data.access_token || `mock_token_${Date.now()}`,
        userInfo: response.data as userInfo,
        message: 'WeChat login successful'
    };
}
else if (response.data && typeof response.data === 'object') {
    // 处理格式C（简单数据格式）
    authResult = {
        success: true,
        token: `temp_token_${Date.now()}`,
        userInfo: response.data as userInfo,
        message: 'Authentication successful'
    };
}
```

## 🔒 **安全要求**

### **1. JWT Token要求**
- **算法**: HS256或RS256
- **过期时间**: 2小时（7200秒）推荐
- **载荷包含**: `openid`, `employeeId`, `exp`, `iat`

### **2. 微信数据解密**
```javascript
// 后端需要实现微信数据解密
const crypto = require('crypto');

function decryptWeChatData(encryptedData, iv, sessionKey) {
    const decipher = crypto.createDecipheriv('aes-128-cbc', 
        Buffer.from(sessionKey, 'base64'), 
        Buffer.from(iv, 'base64')
    );
    
    let decrypted = decipher.update(encryptedData, 'base64', 'utf8');
    decrypted += decipher.final('utf8');
    
    return JSON.parse(decrypted);
}
```

## ⚠ **错误处理**

### **1. 前端期望的错误格式**
```json
{
    "success": false,
    "message": "Invalid login code",
    "error_code": "40029",
    "error_description": "微信登录凭证无效"
}
```

### **2. 常见错误码**
- `40029`: 微信登录code无效或过期
- `40013`: 无效的AppID
- `45011`: 频率限制，每个用户每分钟100次
- `40125`: 无效的密钥

## 🚀 **后端实现建议**

### **1. Node.js/Express示例**
```javascript
// /api/wechat-launch
app.post('/api/wechat-launch', async (req, res) => {
    const { loginCode } = req.body;
    
    try {
        // 1. 向微信服务器验证code
        const wechatResponse = await axios.get(`https://api.weixin.qq.com/sns/jscode2session`, {
            params: {
                appid: process.env.WECHAT_APPID,
                secret: process.env.WECHAT_SECRET,
                js_code: loginCode,
                grant_type: 'authorization_code'
            }
        });
        
        const { openid, session_key } = wechatResponse.data;
        
        if (!openid) {
            return res.status(400).json({
                success: false,
                message: "Invalid login code"
            });
        }
        
        // 2. 查询或创建用户
        let user = await User.findOne({ openid });
        if (!user) {
            user = await User.create({
                openid,
                session_key, // 加密存储
                created_at: new Date()
            });
        } else {
            user.session_key = session_key;
            user.last_login = new Date();
            await user.save();
        }
        
        // 3. 生成JWT
        const token = jwt.sign(
            { 
                openid: user.openid, 
                employeeId: user.employeeId 
            },
            process.env.JWT_SECRET,
            { expiresIn: '2h' }
        );
        
        // 4. 返回前端期望的格式
        res.json({
            success: true,
            token,
            userInfo: {
                openid: user.openid,
                name: user.name,
                employeeId: user.employeeId,
                phone: user.phone,
                department: user.department
            },
            expiresIn: 7200
        });
        
    } catch (error) {
        console.error('Login error:', error);
        res.status(500).json({
            success: false,
            message: "Internal server error"
        });
    }
});
```

### **2. Python/Django示例**
```python
# views.py
from django.http import JsonResponse
from django.views.decorators.csrf import csrf_exempt
import requests
import jwt
import json

@csrf_exempt
def wechat_launch(request):
    if request.method == 'POST':
        data = json.loads(request.body)
        login_code = data.get('loginCode')
        
        try:
            # 1. 向微信服务器验证code
            wechat_response = requests.get(
                'https://api.weixin.qq.com/sns/jscode2session',
                params={
                    'appid': settings.WECHAT_APPID,
                    'secret': settings.WECHAT_SECRET,
                    'js_code': login_code,
                    'grant_type': 'authorization_code'
                }
            )
            
            wechat_data = wechat_response.json()
            openid = wechat_data.get('openid')
            session_key = wechat_data.get('session_key')
            
            if not openid:
                return JsonResponse({
                    'success': False,
                    'message': 'Invalid login code'
                }, status=400)
            
            # 2. 查询或创建用户
            user, created = User.objects.get_or_create(
                openid=openid,
                defaults={'session_key': session_key}
            )
            
            if not created:
                user.session_key = session_key
                user.last_login = timezone.now()
                user.save()
            
            # 3. 生成JWT
            token = jwt.encode({
                'openid': user.openid,
                'employeeId': user.employee_id,
                'exp': timezone.now() + timedelta(hours=2)
            }, settings.JWT_SECRET, algorithm='HS256')
            
            # 4. 返回前端期望的格式
            return JsonResponse({
                'success': True,
                'token': token,
                'userInfo': {
                    'openid': user.openid,
                    'name': user.name,
                    'employeeId': user.employee_id,
                    'phone': user.phone,
                    'department': user.department
                },
                'expiresIn': 7200
            })
            
        except Exception as e:
            return JsonResponse({
                'success': False,
                'message': 'Internal server error'
            }, status=500)
```
